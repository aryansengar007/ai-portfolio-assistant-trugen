# Personal AI Portfolio Assistant using TruGen AI

This project is an interactive AI-powered portfolio assistant that represents my technical profile through conversational interaction.

The assistant helps recruiters and visitors explore my projects, skills, certifications, and experience in real time.

## Features

- Resume-integrated knowledge base responses
- Voice interaction powered by ElevenLabs
- Real-time speech transcription using Deepgram
- Context-aware memory-enabled conversations
- Recruiter-friendly structured project explanations

---

## Technologies Used

- TruGen AI
- GPT OSS 120B (Groq)
- ElevenLabs (Voice)
- Deepgram (Speech-to-Text)

---

## Key Purpose

This assistant demonstrates practical implementation of Generative AI for building intelligent user-facing portfolio systems.
