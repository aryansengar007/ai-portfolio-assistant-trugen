## 🤖 About The Project

An **interactive AI-powered portfolio assistant** built on **TruGen AI** that represents my technical profile through natural conversation. Recruiters and visitors can explore my projects, skills, certifications, and experience in real time — through both **text and voice interaction**.

> 🎙️ This assistant demonstrates a practical implementation of **Generative AI** for building intelligent, user-facing portfolio systems that go beyond a static resume.

<br/>

<div align="center">

| 🧠 AI Engine | 🎙️ Voice | 📝 Speech-to-Text | 💬 Memory |
|:---:|:---:|:---:|:---:|
| GPT OSS 120B via Groq | ElevenLabs synthesis | Deepgram transcription | Context-aware conversations |

</div>

## 🎯 Key Purpose

<br/>

```
 "Instead of reading a static resume — just ask."
```

<br/>

This assistant was built to demonstrate how **Generative AI** can transform a traditional portfolio into an **intelligent, interactive experience**. It enables:

- Recruiters to ask natural questions and get structured answers instantly
- Visitors to explore projects and skills through conversation rather than scrolling
- A real-world application of **LLMs + Voice AI + STT** in a cohesive product
